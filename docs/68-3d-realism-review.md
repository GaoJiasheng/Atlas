# 68 · 3D 模型写实度评审与重做计划

Gavin 2026-11-02：看了八哥（化石主题第 07 章）和恐龙骨架，觉得「这些 3D 模型实在太凑合了」，要做得更写实，先整体 review、列表，再交 Codex 重做。

评审：3 个 Claude Opus 代理在 main（dee51e3）的独立构建上，每个主题按章截图，对照真实参照物评级。逐零件的细节、参照物要点和建议做法在 `docs/68-3d-realism/` 的三份原始评审里：

- 生物与解剖：`review-living.md`
- 肌肉、感官、地球与天体：`review-body-earth-space.md`
- 机器与物理：`review-machines.md`

评级：A 可信，保留；B 不错，打磨细节；C 认得出但粗糙，重做关键零件；D 占位级，整个重做。优先级：1 = 主题主角且明显粗糙（先做），3 = 次要道具。技术图版的配色（象牙白、石墨、发丝线）是有意的，只评造型。

## 三、Codex 重做批次（建议）

1. **第一批（D 和误导事实的）**：恐龙骨架组件、鸟类绑定、树木生成器、港口套件、齿轮、自行车，以及用它们重做化石与恐龙骨架、红树林、集装箱港口、地球内部、蒸汽机、能量转换的自行车。
2. **第二批（C，优先级 1–2）**：行星套件（太阳系、太阳地球月亮）、外耳和听小骨、土星五号（以 NASA 公有领域模型为参照）、B200 前面板、珊瑚、青蛙与鸡、花与种子、生物分类、细胞、声音、水循环、热。
3. **第三批（B 打磨）**：健身房套件（肌肉 6 个主题）、其余 B 级主题的细节。

每批照旧：Codex 施工 → Claude 浏览器验收（同角度新旧对比截图）→ 合并上线。模型改动不能改变零件 id、数目和教学事实；造型改了，零件说明里的数字仍要对得上。
