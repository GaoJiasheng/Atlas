# 数据清单 / Data inventory

本主题没有地图、外部实测数据文件、GLB 或运行时数据服务。外部数据集 0 个，下载数据 0 bytes。公开来源仅支撑事实，不复制其图像或表格。

- `data/parts.json`：原创程序化形状、三个展台、顺序弧、命名姿态，以及 `table` 状态表。所有坐标和摆放尺度为 DESIGN 显示单位，不是生物测量。
- `data/sources.json`：S1–S22 来源注册，S22 为原创设计研究。
- `data/glossary.json`：本主题真正使用的双语名词与定义。
- `ILLUSTRATIONS.md`：批准插图的加工、SHA-256 与 mosquito 复用链。
