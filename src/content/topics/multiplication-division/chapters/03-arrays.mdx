<Lang en>

In the last step you counted <Term id="equal-groups">equal groups</Term> with jumps. Now the groups are lined up neatly, so you can see the same things in two ways.

An illustration made for this lesson, not a real block.", zh: "窗户排成一样多的行和列，就是一个阵列。为本课画的示意图，不是真实的组屋。" }} />

Look at the <Beat n={1}>3 groups of eggs</Beat>. Each ring holds 4 eggs, so you can add the groups: 4 + 4 + 4 = 12. That is 3 groups of 4.

Now <Beat n={2}>line each group up as a row</Beat>. A row goes across. There are 3 rows down the side, with 4 eggs across each row. Things set out in equal rows like this make an <Term id="array">array</Term>. Each row is one group, so the array is 3 × 4 = 12: the number of rows, times the number in each row. Every egg is still there.

Keep the tray still and <Beat n={3}>read it by columns</Beat>. A column goes from top to bottom. There are 4 columns, with 3 eggs in each. Counting by columns gives 4 × 3 = 12. It is the same 12 eggs, counted another way.

Now <Beat n={4}>turn the tray a quarter turn</Beat>. The columns have become rows: 4 rows of 3. Nothing was added or taken away, so 3 × 4 = 4 × 3. You can multiply two numbers in either order and get the same answer. This is useful: if you know 2 × 9, you also know 9 × 2.

A common mistake is to make 4 rows of 3 when the question asks for 3 rows of 4. The total is the same, but the rows and the number in each row are swapped. When a question names the rows, count the rows down the side first.

When you are ready, <Task id="arrays">try one question</Task> on making an array or finding how many it holds.

<Lang zh>

上一步用跳数来数<Term id="equal-groups">相同的几组</Term>。这一步把每组排得整整齐齐，同样的东西就能用两种方法来看。这样的排法在生活里到处都有：组屋的窗户、教室里的座位、托盘里的鸡蛋，都是一行一行、一列一列排好的。

An illustration made for this lesson, not a real block.", zh: "窗户排成一样多的行和列，就是一个阵列。为本课画的示意图，不是真实的组屋。" }} />

先看<Beat n={1}>3 组鸡蛋</Beat>。每个圈里有 4 个，可以一组一组地加：4 + 4 + 4 = 12，也就是 3 组、每组 4 个。

再<Beat n={2}>把每组排成一行</Beat>。行是横着的。从上往下数，一共 3 行；每行横着有 4 个。像这样排成一样多的几行，就叫<Term id="array">阵列</Term>。一行就是一组，所以这个阵列是 3 × 4 = 12：行数乘每行的个数。鸡蛋只是排整齐了，一个也没少。

托盘不动，<Beat n={3}>按列来看</Beat>。列是竖着的，从上到下。一共 4 列，每列 3 个。按列数，就是 4 × 3 = 12。还是这 12 个鸡蛋，只是换了一种数法。

接着<Beat n={4}>把托盘转四分之一圈</Beat>。原来的列变成了行：4 行，每行 3 个。一个没多，一个没少，所以 3 × 4 = 4 × 3。两个数相乘，换个顺序，得数不变。这一点很有用：会算 2 × 9，也就会算 9 × 2；会了一道，等于会了两道。

常见的错误是：题目要 3 行、每行 4 个，却排成了 4 行、每行 3 个。总数一样，可是行数和每行的个数对调了。题目说了几行，就先竖着数行数，再横着数每行几个。

准备好了，就<Task id="arrays">做一道小题</Task>：排一个阵列，或者算出阵列里一共有多少。
