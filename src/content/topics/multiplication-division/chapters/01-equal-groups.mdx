<Lang en>

You already know how to count things one by one. This step shows a quicker way, and it works only when the groups are the same size.

<Figure src="figures/multiplication-division-hawker-trays" alt={{ en: "Pencil drawing of a hawker stall's glass cabinet seen from the front: three shelves with three identical round trays on each, every tray holding four small square kueh set out the same way, with serving tongs on the counter.", zh: "从正面看的小贩摊玻璃柜铅笔画：三层架子，每层摆着 3 个一样的圆托盘，每个托盘里都整齐地放着 4 块小方形 kueh，柜台上放着一把夹子。" }} caption={{ en: "Every tray holds the same number of kueh: equal groups. An illustration made for this lesson.", zh: "每个托盘里的 kueh 一样多，这就是相同的几组。为本课画的示意图。" }} />

Look at the <Beat n={1}>kueh scattered on the tray</Beat>. To find how many there are, you can touch each piece once and count: 1, 2, 3 … 12. That works, but with more kueh it would be slow, and it is easy to count one piece twice.

Now <Beat n={2}>put 3 on each plate</Beat>. There are 4 plates, and every plate holds 3. These are <Term id="equal-groups">equal groups</Term>. You can count a whole plate at a time: 3 + 3 + 3 + 3 = 12. Moving the kueh changed where they are, not how many there are.

The kueh can also go on plates <Beat n={3}>holding 2, 5 and 5</Beat>. They still add up to 12, but the groups are not equal. There is no single number that tells you how many are on each plate, so you cannot count them as "3 groups of" anything.

Go back to <Beat n={4}>4 plates with 3 on each</Beat>. Equal groups can be written with the sign for <Term id="multiplication">multiplication</Term>: 4 × 3 = 12. Read 4 × 3 as "4 groups of 3". The first number says how many groups there are; the second says how many are in each group. 4 × 3 is a short way to write 3 + 3 + 3 + 3.

Two mistakes are common. One is to call groups like 2, 5 and 5 "3 groups": check that every group holds the same number first. The other is to add the two numbers: 4 + 3 = 7 adds the number of plates to the number on one plate, but it does not count the kueh.

When you are ready, <Task id="equal-groups">try one question</Task> on making equal groups or finding how many there are in all.

<Lang zh>

一个一个地数，你已经会了。这一步讲一种更快的数法，不过它有个条件：每一组要一样多。

<Figure src="figures/multiplication-division-hawker-trays" alt={{ en: "Pencil drawing of a hawker stall's glass cabinet seen from the front: three shelves with three identical round trays on each, every tray holding four small square kueh set out the same way, with serving tongs on the counter.", zh: "从正面看的小贩摊玻璃柜铅笔画：三层架子，每层摆着 3 个一样的圆托盘，每个托盘里都整齐地放着 4 块小方形 kueh，柜台上放着一把夹子。" }} caption={{ en: "Every tray holds the same number of kueh: equal groups. An illustration made for this lesson.", zh: "每个托盘里的 kueh 一样多，这就是相同的几组。为本课画的示意图。" }} />

先看<Beat n={1}>托盘上散放的 kueh</Beat>。想知道有多少块，可以每块点一下，一边点一边数：1、2、3……12。这样数没有错，可是块数一多就很慢，还容易把同一块数两次。

再<Beat n={2}>每个盘子放 3 块</Beat>。现在有 4 个盘子，每盘都是 3 块，这就是<Term id="equal-groups">相同的几组</Term>。这时可以一盘一盘地数：3 + 3 + 3 + 3 = 12。kueh 只是换了地方，块数没有变。

同样 12 块，也可以<Beat n={3}>放成 2 块、5 块、5 块</Beat>。加起来还是 12，可是每盘不一样多。说不出"每盘几块"，也就不能说成"3 组，每组几块"。

回到<Beat n={4}>4 个盘子、每盘 3 块</Beat>。一样多的几组，可以用<Term id="multiplication">乘法</Term>的符号 × 来写：4 × 3 = 12。4 × 3 读作"4 乘 3"，意思是 4 组、每组 3 个：前面的数说有几组，后面的数说每组几个。4 × 3 就是 3 + 3 + 3 + 3 的简便写法。组数越多，这种写法越省事：10 组、每组 3 个，写成 10 × 3 就行了，不用写十个 3 连加。

这里有两个常见的错误。一是把 2 块、5 块、5 块这样的分法也叫"3 组"：先看清每组是不是一样多，再说几组几个。二是把两个数加起来：4 + 3 = 7 是把盘子数和一盘的块数相加，数的不是 kueh。

准备好了，就<Task id="equal-groups">做一道小题</Task>：分出相同的几组，或者算出一共有多少。
