<Lang en>

You have counted several <Term id="equal-parts">equal parts</Term> to name a <Term id="fraction">fraction</Term>, and seen that all the parts together make one <Term id="whole">whole</Term>. Now you can show that same amount as a place on a <Term id="number-line">number line</Term>.

Look at <Beat n={1}>the strip above the line</Beat>. Its ends line up with 0 and 1, so the stretch from 0 to 1 represents one whole strip. The marks divide that stretch into 4 equal jumps. A jump is the space between two neighbouring marks. Each jump is as long as one of the strip's 4 equal parts.

Start at 0 and <Beat n={2}>make one jump to the right</Beat>. You land on <Frac n={1} d={4} />, at the first mark after 0. This jump matches one quarter of the strip. The fraction names how far you have travelled from 0, using the whole stretch as your whole. At 0, you have not made any jumps yet.

Now <Beat n={3}>count three equal jumps</Beat> from 0. Each jump is <Frac n={1} d={4} />, so three of them take you to <Frac n={3} d={4} />. The top number, the <Term id="numerator">numerator</Term>, counts the jumps you make. The bottom number, the <Term id="denominator">denominator</Term>, counts all 4 equal jumps in the whole. One more jump reaches 1, which is <Frac n={4} d={4} />. Counting marks instead of jumps is a mistake: there are 5 marks but only 4 jumps. The mark at 0 is your starting point, not a jump.

Next, <Beat n={4}>look at the eight equal jumps</Beat>. The whole still runs from 0 to 1, but each jump is now shorter: <Frac n={1} d={8} />. Five jumps from 0 land on <Frac n={5} d={8} />. Four jumps reach the middle, so the fifth takes you a little past it.

<More title={{ en: "Levels and flights of stairs", zh: "楼层和楼梯" }}>

In an HDB block, walking from level 1 up to level 4 takes 3 flights of stairs, not 4. The levels are like the marks; the flights between them are like the jumps. On a number line we count the jumps, just as we count the flights we climb.

</More>

</Lang>

<Lang zh>

你已经会数好几份<Term id="equal-parts">平均分</Term>出来的部分，说出一个<Term id="fraction">分数</Term>，也知道所有的份合起来是一个<Term id="whole">整体</Term>。现在把同样的量画成<Term id="number-line">数轴</Term>上的一个位置。

看<Beat n={1}>数轴上方的纸条</Beat>。纸条的两端对着 0 和 1，所以从 0 到 1 这一段就代表一整条纸条。刻度把这一段平均分成 4 段。一段就是相邻两条刻度之间的距离，和纸条的一份一样长。

从 0 出发，<Beat n={2}>向右跳 1 段</Beat>，落在 <Frac n={1} d={4} />，也就是 0 后面的第一条刻度。这一段正好对着纸条的四分之一。分数说的是你从 0 走了多远，走的路以 0 到 1 为一个整体。站在 0 的时候，你还一段也没跳。

现在从 0 开始<Beat n={3}>数 3 段</Beat>。每段是 <Frac n={1} d={4} />，3 段就到 <Frac n={3} d={4} />。上面的数是<Term id="numerator">分子</Term>，数你跳了几段；下面的数是<Term id="denominator">分母</Term>，数整体一共平均分成几段。再跳一段就到 1，也就是 <Frac n={4} d={4} />。数刻度线而不数段数是常见的错误：这里有 5 条刻度线，却只有 4 段。0 那条线是起点，不是一段。

接着看<Beat n={4}>平均分成 8 段的数轴</Beat>。整体还是从 0 到 1，可是每段短了，是 <Frac n={1} d={8} />。从 0 跳 5 段，落在 <Frac n={5} d={8} />。跳 4 段正好到中间，所以第 5 段让你比中间多走一点。

<More title={{ en: "Levels and flights of stairs", zh: "楼层和楼梯" }}>

在组屋里，从 1 楼走到 4 楼，要爬 3 段楼梯，不是 4 段。楼层像刻度线，楼层之间的楼梯像数轴上的段。在数轴上我们数段，就像数自己爬了几段楼梯。

</More>
