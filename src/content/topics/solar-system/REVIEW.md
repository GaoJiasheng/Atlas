## 各章需要审的重点

| 章 | 请审正文与字幕的判断 |
|---|---|
| 00 读懂模型 | 三种尺度说明足够清楚；10mm地球、约117m天文单位的例子易懂。 |
| 01 我们的恒星 | 太阳是等离子体，核聚变不是普通燃烧；表面棚灯只显形，发光/反光靠独立示意光路解释。 |
| 02 八个世界 | 大小、参考半长轴、公转周期分开；不把“冰巨行星”讲成有冰地面的星球。 |
| 03 较小的伴星 | 卫星仍随母体绕太阳；稀疏小行星带不表示实际密度；彗尾反太阳，不是拖在速度后面；流星是大气发光。彗尾试验请用第四拍。 |
| 04 穿过空气 | 起伏发生在接收信号；行星“通常”闪得少，不能作绝对辨星规则。 |
| 05 转动的视点 | 比较两小时与不同日期；外部小地球仅是静态观察者参照，不假称同步自转。 |
| 06 新加坡的星空图案 | 图案和距离分离；星表上在地平线上方不保证真实能见。中文星座/文化措辞请复核。 |
| 07 行星之外 | 光年、光行时间、银河系盘直径不同；比邻星不冒充明亮的半人马座α双星。 |
