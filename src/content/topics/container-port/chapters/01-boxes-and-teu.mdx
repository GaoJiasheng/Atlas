<Lang en>

Look at the separate sample boxes. We can count the boxes themselves or compare their sizes using a common unit. A <Num s="S8">20-foot</Num> container counts as <Num s="S8">1 TEU</Num>, a <Term id="teu">twenty-foot equivalent unit</Term>. A <Num s="S8">40-foot</Num> container counts as <Num s="S8">2 TEU</Num>, while remaining a single physical box.

Set the sample controls to <Num s="S1">two short boxes and one long box</Num>. Count the objects first: <Num s="S1">3 boxes</Num>. Now count the equivalent units: <Num s="S1">1 + 1 + 2 = 4 TEU</Num>. The answer changes because the unit changes. Try adding or removing one length at a time and record both readings.

The names describe size groups. The actual outside lengths used here are <Num s="S9">6.058 m</Num> and <Num s="S9">12.192 m</Num>. Two short boxes placed end to end are therefore slightly shorter than a long one. The foot names are size labels, rather than exact outside lengths.

TEU tells us nothing about how heavy the contents are. An empty box and a loaded box of the same size still have the same TEU count. To find mass, we need information about the particular container and its cargo. The counting controls therefore give no mass reading.

Adding the short boxes’ lengths gives <Num s="S1">6.058 + 6.058 = 12.116 m</Num>, a difference of <Num s="S1">0.076 m</Num> from the long box. Standard-height examples are <Num s="S9">2.591 m</Num> high; a high-cube class is <Num s="S9">2.896 m</Num> high. Other container types also exist.

</More>

<Lang zh>

看这些分开放的样箱。可以数箱子的只数，也可以用共同单位比较箱子的大小。<Num s="S8">20 英尺</Num>集装箱记为 <Num s="S8">1 TEU</Num>，TEU 是<Term id="teu">二十英尺当量单位</Term>。<Num s="S8">40 英尺</Num>箱记为 <Num s="S8">2 TEU</Num>，但它仍然是一只箱子。

把控件设成<Num s="S1">两只短箱、一只长箱</Num>。先数物体：共有 <Num s="S1">3 只箱</Num>。再按共同单位数：<Num s="S1">1＋1＋2＝4 TEU</Num>。单位变了，所以答案也变了。试着每次只增减一种箱，并把两项读数记下来。

箱子的名称说的是尺寸类别。本例采用的实际外长是 <Num s="S9">6.058 米</Num>和 <Num s="S9">12.192 米</Num>。因此，两只短箱首尾相接，仍比一只长箱略短。英尺名称是尺寸类别，不是精确外长。

TEU 不说明箱里的货物有多重。同样尺寸的空箱和装货箱，TEU 数仍相同。要知道质量，必须另查这只箱子和它装的货物。所以，计数控件不显示质量；长箱记两份，也不代表货物一定重两倍。
