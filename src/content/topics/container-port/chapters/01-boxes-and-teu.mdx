<Lang en>

Look at the separate sample boxes. Counting objects and comparing container capacity use different units. A <Num s="S8">20-foot</Num> container counts as <Num s="S8">1 TEU</Num>, a <Term id="teu">twenty-foot equivalent unit</Term>. A <Num s="S8">40-foot</Num> container counts as <Num s="S8">2 TEU</Num>, while remaining a single physical box.

Set the sample controls to <Num s="S1">two short boxes and one long box</Num>. Count the objects first: <Num s="S1">3 boxes</Num>. Now count the equivalent units: <Num s="S1">1 + 1 + 2 = 4 TEU</Num>. The answer changes because the unit changes; no extra box has appeared. Try adding or removing one length at a time and record both readings.

The names describe size classes. The selected external lengths are <Num s="S9">6.058 m</Num> and <Num s="S9">12.192 m</Num>. Two short boxes placed end to end are therefore slightly shorter than a long one. This is why the drawing compares nominal lengths rather than pretending that the short pair is exactly the same length as the long box.

TEU tells us nothing about how heavy the contents are. An empty box and a loaded box of the same size still have the same TEU count. To find mass, we need information about the particular container and its cargo. The model deliberately gives no mass reading from these counting controls.

The model’s arithmetic gives <Num s="S1">6.058 + 6.058 = 12.116 m</Num>, leaving <Num s="S1">0.076 m</Num> compared with the selected long box. Standard-height examples are <Num s="S9">2.591 m</Num> high; a high-cube class is <Num s="S9">2.896 m</Num> high. These examples do not cover every container type.

看这些分开放的样箱。数物体的只数，和用共同单位比较集装箱，得到的数字不一定相同。<Num s="S8">20 英尺</Num>集装箱记为 <Num s="S8">1 TEU</Num>，TEU 是<Term id="teu">二十英尺当量单位</Term>。<Num s="S8">40 英尺</Num>箱记为 <Num s="S8">2 TEU</Num>，但它仍然是一只箱子。

把控件设成<Num s="S1">两只短箱、一只长箱</Num>。先数物体：共有 <Num s="S1">3 只箱</Num>。再按共同单位数：<Num s="S1">1＋1＋2＝4 TEU</Num>。不是凭空多出了一只箱子，而是计数用的单位变了。试着每次只增减一种箱，并把两项读数记下来。

箱子的名称说的是尺寸类别。本例采用的实际外长是 <Num s="S9">6.058 米</Num>和 <Num s="S9">12.192 米</Num>。因此，两只短箱首尾相接，仍比一只长箱略短。图里比较的是名义长度，不能把名称当作以米表示的精确外长，也不能拿插图当尺来量。

TEU 不说明箱里的货物有多重。同样尺寸的空箱和装货箱，TEU 数仍相同。要知道质量，必须另查这只箱子和它装的货物。这里的计数控件不会推算质量；长箱记两份，也不代表里面一定有短箱两倍重的货。
