<Lang en>

The low carrier connects the quay to the yard. An <Term id="agv">automated guided vehicle</Term>, or AGV, moves loads horizontally under automatic guidance. It does not perform the quay crane’s lift. In this model, the box rests on its deck while travelling; the vehicle’s shape is generic, rather than a particular manufacturer’s design.

The yard crane spans the container rows. It can lift containers within the yard, where waiting boxes need places from which they can later be retrieved. Look at the example stack. Its corner positions line up vertically. This drawing illustrates the relationship of the corners, without specifying a permissible stacking height for a real terminal.

Select the bottom target box. With <Num s="S1">two boxes</Num> above it in this example, the target cannot be taken straight out from above. The upper boxes must be moved first. Moving a box that blocks access is called a <Term id="rehandle">rehandle</Term> here. The before-and-after views show which boxes have changed positions, rather than claiming a complete safe lifting route.

Choose the cleared state, then the retrieved state. The model counts <Num s="S1">2 rehandles plus 1 retrieval lift</Num>. Now set the number above to zero and compare the readings. Only the target’s retrieval remains. Record both cases while keeping the target in the same bottom slot. An extra box in storage can affect access to another box; storage is about arrangement as well as available space.

<More title={{ en: "What the move count includes", zh: "次数算到哪里" }}>

Here, retrieval lifts equal the number above plus <Num s="S1">1</Num>. The count stops when the target is retrieved. Putting the other boxes back would add work, but those restoration moves are excluded. The parking places are schematic, not a recommendation for organising an actual yard.

</More>

低平运输车把岸边和堆场接起来。<Term id="agv">自动导引车</Term>常用英文简称 AGV，按自动导引水平运送货物，不承担岸桥的起吊动作。在本模型里，箱子靠车的承载面托住。车的外形是通用示意，不对应某个厂商或车型。

场桥跨在箱列上方，负责堆场内的起吊。暂存的箱子不只要放得下，还要能按需要再取出来。看看示例箱堆，上下箱子的角部位置对齐。这个画法说明角部的关系，不是在规定真实码头允许堆多少层，也不表示只有画出的因素才影响堆放。
