<Lang en>

The low carrier connects the quay to the yard. An <Term id="agv">automated guided vehicle</Term>, or AGV, follows automatic guidance to carry loads across the ground. The quay crane does the lifting. The box rests on the carrier’s deck as it travels.

The yard crane spans the rows and lifts containers within the yard. Waiting boxes need places where they can be reached later. Look at the example stack. Its corners line up vertically.

Select the bottom target box. The <Num s="S1">two boxes</Num> above it block the way. The upper boxes must be moved first. Moving a box that blocks access is called a <Term id="rehandle">rehandle</Term> here. Compare the views to see which boxes move.

Choose “Upper boxes moved”, then “Target retrieved”. The model counts <Num s="S1">2 rehandles plus 1 retrieval lift</Num>. Now set the number above to zero and compare the readings. Only the target’s retrieval remains. Record both cases while keeping the target in the same bottom slot. An extra box can block access to another. A yard needs both space and a useful arrangement of boxes.

<More title={{ en: "What the move count includes", zh: "次数算到哪里" }}>

The total number of lifts is the number of boxes above the target plus <Num s="S1">1</Num>. The count stops when the target is retrieved. Putting the other boxes back would add work, but those restoration moves are excluded. The temporary spaces show where the upper boxes wait.

</More>

<More title={{ en: "Comparing the yard views", zh: "比较堆场的前后画面" }}>

The blocking boxes jump to their new positions. These views show the result of each move, rather than a safe lifting route. They do not set real stacking limits or calculate stability or handling speed. The working box traced from the ship and the target in this separate yard experiment are different objects.

</More>

<Lang zh>

低平运输车把岸边和堆场接起来。<Term id="agv">自动导引车</Term>常用英文简称 AGV，按自动导引在地面上运送货物。起吊由岸桥负责。行驶时，箱子放在车的承载面上。

场桥跨在箱列上方，负责堆场内的起吊。暂存的箱子不只要放得下，还要能按需要再取出来。看看示例箱堆，上下箱子的角部位置对齐。

选中最下面的目标箱。本例中，上方有 <Num s="S1">2 只箱</Num>，挡住从上面取出目标的位置，必须先把它们移开。这里把先移开阻挡箱的动作称为<Term id="rehandle">翻箱</Term>。比较前后画面，看看哪些箱子换了位置。

先选“移开上层箱”，再选“取出目标箱”。模型共数了 <Num s="S1">2 次翻箱加 1 次取目标</Num>。再把上方箱数设成零，比较读数，就只剩取目标的动作。保持目标箱的底层位置不变，记下两种情况。多放一只箱子，也可能挡住另一只箱子。堆场既要有空间，也要安排好箱子的位置。

<More title={{ en: "What the move count includes", zh: "次数算到哪里" }}>

这里总起吊次数等于上方箱数加 <Num s="S1">1</Num>，取出目标就停止计数。把其它箱子再放回去还需要动作，但本模型不计这些复位动作。移箱位置表示上层箱暂时放在哪里。

</More>
