<Lang en>

Return to the working box from the ship. In the first view it has reached the carrier. In the next it waits in the yard. Its position changes, but it is still the same selected object. The model does not create a second copy when the box moves to a new stage.

Now look towards the onward vessel. The same box joins that ship for another destination. This illustrates one common transhipment journey: arrival by sea, a landside transfer and departure by sea. The port is an intermediate connection in the cargo’s journey. Unloading here therefore does not mean that the cargo’s final destination is here.

The separate local-delivery box represents another destination for cargo. It is a different box, so it does not replace the identity of the one being traced. Comparing the two makes the distinction visible: some cargo continues overseas, while other cargo is delivered into the local economy. This is a diagram of possible journeys, not a statement about their shares of port traffic.

A yard can provide a place to wait between these stages. The arrival and departure of the vessels need not happen together. The model advances through named positions so that each connection can be inspected. It does not use an actual vessel schedule, predict waiting times or show a geographic route. Use the index to return to the working box after selecting the onward ship, and check that its location matches the current step.

回到刚才从船上卸下的工作箱。先看它到了运输车上，再看它在堆场等待。位置变了，选中的仍是同一只箱子。模型不会在进入下一个环节时，另外复制一只来代替它；你可以沿同一个对象继续追踪。

接着看接续船。同一只工作箱装上这条船，前往另一个目的地。这说明一种常见的转运过程：海上到达，经过岸上搬运，再从海上离开。港口是旅程中的中间连接点。因此，在这里卸货，不代表这里就是货物最终要去的地方。

另一个本地交付箱代表不同去向。它是另一只箱，不取代我们一直追踪的工作箱。把两者放在一起比较，就能看清：有的货继续出海，有的货交付本地。这只是可能旅程的对照，没有表示两种去向各占港口货量的多少，也不能按模型里箱子的数量推算比例。

堆场能在这些环节之间提供暂存位置。前后两条船不一定同时到达，所以箱子可能需要等待。模型用几个具名位置逐步展示连接关系，不采用真实船期，不预测等待多久，也没有把示意位移当作地理航线。选过接续船后，可从索引回到工作箱，核对这一拍它在哪里。
