# Geography engine fixture

Draft fixture using three real country features (Singapore, Brunei Darussalam, Timor-Leste), original river features and country-scale cases copied from southeast-asia. Natural Earth public-domain geometry, unchanged source coordinates. This is an intentionally incomplete country subset for engine testing, not a regional membership chart. Monthly files are reused by reference, not copied. The full provenance and SHA-256 source inventory are in southeast-asia/provenance.
