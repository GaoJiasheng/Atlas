# Sample directed food web

Draft engine fixture for docs/53 §4. This topic uses simple spheres, sample evidence and the same six-node teaching DAG as the contract. It is not a scientific reference topic.

- S1: Sample relation evidence. All four evidence categories are exercised, including their notes and source popovers.
- S2: Sample design study. Seven remove values, four inspection values and two tide values form 56 combinations. The existing table sim stores three independent experiments: web (7 rows), inspection (28 rows) and tide-pose (14 rows), for 20 number/state outputs. Every table row cites S2.

Counts describe only the selected graph. Producer support travels through present nodes; active relations start at a supported node and end at a present node. No population dynamics, energy percentages or death times are calculated. Tide changes only the three pose/display readings.

The background chapter deliberately has no try-it card, so narrow-screen access to the directed card can be verified independently. The experimental chapter exercises prediction and recording. Stage spheres are selection targets; this fixture concentrates on the optional card rather than habitat geometry or stage bindings.
