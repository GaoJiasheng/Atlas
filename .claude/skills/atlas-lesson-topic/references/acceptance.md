# 验收清单（发布前全部打勾）

## 门槛
- [ ] `pnpm check`、`pnpm validate`（0 error、0 warning）、`pnpm test`、`pnpm build`、`pnpm e2e` 全绿
- [ ] `pnpm shoot <slug> --beats --tasks --keys --layout --locale en,zh --theme paper,cinema`：0 节拍失败、0 题目失败（每道题库题与练习题的错例诊断正确、解法做完）、键位 0 失败、七个尺寸 0 布局问题、console 干净、无外部请求

## 讲解优先
- [ ] 每章 3–5 个讲解拍 + 1 道小测；正文里只有最后一句的一个 `<Task>`；没有"题单章"（练习章除外）
- [ ] 逐张看 `beat-*.png`：每拍的模型、算式、字幕说的是同一件事；过渡（切、折、合、化、涂、划、放、换模型）看得出变化；常见误解至少有一拍正面讲
- [ ] 正文 EN 250–350 词 / ZH 400–550 字，按拍序，每拍一个 `<Beat n>`，链接文字是句子的一部分；读完不看舞台也能懂
- [ ] 题库每步 8–10 道，同一思想、不同数字 / 模型 / 误解；抽题不进 URL；"再来一道"换题、"跳过"去下一章；演示在小测拍停住，答对 / 看答案 / 跳过后才走
- [ ] 练习 6–10 道固定题，一次检查，总结页一句话 + 表 + 再做一次

## HUD 铁律（docs/08 §2）
- [ ] 底部只有章节轴：段 = 章、圆点 = 讲解拍、方块 = 小测 / 练习题；点圆点舞台落到那一拍（不进演示，节拍行换字幕，URL 带 `b`），点方块打开小测；`,` / `.` 跨章翻拍；⌄ 收成发丝线
- [ ] 没有底部面板；算式在模型下方；左列 PLATE 块（模型 · 份数 · 标记 · 分数）可收起、手机隐藏；右上卡 FRACTION 不先说答案
- [ ] 阅读面板顺序：章头 → 节拍行 → 小测托盘 → 正文 → 本章索引（要点 + 课纲对照 + 去做小测）
- [ ] 1024 px 以下小测托盘停在舞台上、章节轴上方，模型在它上面放得下；手机（390 × 844）章节轴只剩章号、节拍行 ‹ › 在阅读抽屉里、触控目标 ≥ 44 px、无横向滚动

## 内容与事实
- [ ] 课纲原文逐字、页码对；每步 `lo` 对得上；桥（超纲）步标了 `bridge`
- [ ] 数字约束（分母范围、结果范围、相关分母……）由 validate 与 lesson.test 证明
- [ ] 口吻抽查：无感叹号、无"wrong / 错了 / 太棒了 / easy"、每条错误反馈说原因和下一步
- [ ] 两种语言齐全，中文独立成文，术语符合 spec 术语表；名词表的词在 EN、ZH 正文里第一次出现都包了 `<Term>`
- [ ] 不依赖颜色：灰度截图能分辨给定的 / 新加上的 / 拿走的 / 答案；对错只用文字和 ✓ / ○
- [ ] 无 TODO、占位文字、死代码、console 噪音
