# 写作规则（课主题）

## 讲解节拍（`beats[].caption`）
- 一拍讲一件事：这一拍舞台上**看什么**，以及**为什么**。1–2 句，EN ≤ 35 词，ZH ≤ 60 字。
- 字幕也是朗读文本：分数写 `{3/4}`（朗读成 "three quarters / 四分之三"），不写 "3/4" 纯文本。
- 顺序：已知 → 新的模型动作 → 符号 → 结论。第一拍接上一步，最后一拍给结论或应用（文字题配模型图）。
- 算式（`equation`）是同一件事的抽象写法，短：`{1/2} = {2/4}`、`{2/7} + {3/7} = {5/7}`、`3 × {1/4} = {3/4}`；比较用 `<` `>`，未知用 `?`；不在算式里写解释文字。
- 常见误解至少在一拍里正面讲（"三块不一样大，不是三分之一"），不要等孩子做错才出现。

## 正文（章节 MDX，`<Lang en>` / `<Lang zh>`）
- 篇幅：EN 250–350 词、ZH 400–550 字（不含 `<More>` 小框）；小框 ≤ 120 词，放在最后一句之前。
- 结构：一两句接上一章 → 每拍一段（按拍序，每段用一次 `<Beat n={k}>短语</Beat>`，链接文字是句子的一部分）→ 一两句讲本步的常见错误和为什么错 → 最后一句引出小测：`准备好了，就<Task id="<step-id>">做一道小题</Task>……`（全章只有这一个 `<Task>`）。
- 分数一律 `<Frac n={3} d={4} />`（带分数 `w`）；名词第一次出现包 `<Term id>`（id 必须在 glossary.json 里）；数字来源用 `<Num s>`（只在背景章与课纲表里常用）。
- `<` 写成 `&lt;`；`>` 可直接写或 `&gt;`。
- 句子短，P3 孩子能读：一句一个意思；先具体（"8 equal parts"）后术语（"denominator"）。
- 英文可由 Codex 起草（brief 见 `references/codex-text-brief.md`），Claude 逐句核对与拍、数字、术语一致。

## 中文
- 独立成文，不逐词翻译；句子长短不必和英文一致。
- 术语以中国大陆人教版为底，新加坡华文习惯为准：分子、分母、平均分、单位分数、同分母分数、异分母分数、等值分数、最简分数、相关分数（分母成倍数）、模型图、数轴、带分数、假分数。
- 读法："四分之三""一又四分之三"；"二分之一"先说分母（中文顺序正好是"先数整体几份，再数取几份"，可以在正文里点出来）。
- 新加坡情境词保留原文：kaya 吐司、prata、kueh、组屋、MRT；人名保留拼写（Mei Ling、Aisha、Ravi、Wei Jie……）。
- 标点用全角；分数与运算符之间的空格照英文写法（`<Frac> = <Frac>`），排版由 frac-glue 处理。

## 小测题（题库）与练习
- `prompt`：一句话说做什么，EN ≤ 120 字符、ZH ≤ 40 字（`{a/b}` 记一字）。
- `guide`：怎么想，1–3 句，不直接给答案。
- `hints`：1–3 级（看哪里 → 用什么办法 → 几乎是答案）；练习题只有 1 级。
- `feedback.correct`："Yes. / 对。" + 为什么。`fallback`："Not yet. / 还没对。" + 看哪里。`wrong[]`：每条 = 一个误解 code + 具体原因 + 下一步，配一个能被诊断成这个 code 的 `sample`。`reveal`：看答案时的解释。
- 不说 "wrong / 错了 / 太棒了 / easy"；不用感叹号；不出现品牌、价格、比赛排名。
- 同一题库里的题：同一思想，换数字、换模型（条 / 圆 / 数轴）、换情境、换针对的误解；不要十道一模一样只换数字。
