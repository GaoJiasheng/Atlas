## 先选原型

原型决定分区方式、Tier-1 清单、模式、镜头和右上卡（skill `industrial-3d-showcase` 的 `archetypes.md`）。Atlas 的右上卡固定是零件链路、底部三面板固定是 ARCHITECTURE / DETAIL / STATE，原型只影响分区和取舍：

| 原型 | 例子 | 分区（01–05） | Tier-1 重点 | 本引擎里怎么做 |
|---|---|---|---|---|
| 封闭设备（§2） | 空调、冰箱、洗衣机、电脑、电梯 | 按位置 / 功能模块（室内机、连接管、室外机）；只有流的组放最后 | 外包络比例、面板开口、核心功能体（换热器、电机）、识别度最高的管路 | 外壳拆成薄板设 `shell`；章节 `hide` 外壳露出内部；X-RAY + FLOW 是主要读法 |
| 旋转机械（§1） | 风力发电机、喷气发动机、水泵、自行车传动 | 沿介质 / 力的流向（进气 → 压缩 → 燃烧 → 涡轮 → 排气） | 主轴连续、逐级变化的叶片、核心过程区、末端大截面 | `blades` / `lathe`；`rotate` 动画用可读转速；CUTAWAY 沿轴的剖面 |
| 生物 / 有机体（§3 改写） | 蚱蜢、心脏、花、人耳、鱼鳃 | 按身体分区（头 / 胸 / 腹）或系统（骨骼、肌肉、消化、循环、呼吸） | 整体剪影与体节数、附肢数量与关节、标志性器官的位置和相对大小 | 体节用 `lathe` / `extrude` + `repeat`，左右对称件用 `mirror`；系统做成组，用 LAYERS 开关；"流"表示血液、空气、食物的路径（`stops` 表状态变化）；比例与位置按参考图，不夸张 |

混合主体选最能解释工作原理的那个原型，在决策表里写明。

## 4. 流

颜色语义（每色一个意思）：〔如 hot = 热 / neutral = 接近环境 / cold = 冷〕；状态靠粒子疏密和速度（液体密而慢、气体疏而快）。首尾相接的分段流 `ends: open`，各段 `count / 长度 × speed` 大致相等。

| id | group | 段 | 路径（按零件） | 约长 m | speed | count | size × | spread | stops（u: 色） | ends | clip | parts |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

合计〔N〕条 = 运转时 +〔N〕次绘制（< 10）。
